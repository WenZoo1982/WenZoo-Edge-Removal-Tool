# WenZoo Edge Removal Tool

**版本：v0.5.1**

WenZoo Edge Removal Tool 是一款面向 Windows 的 PowerShell 工具，用于移除传统桌面版 Microsoft Edge，并提供备份与恢复功能。

> [!CAUTION]
> 本工具会修改系统服务、计划任务、文件及注册表，具有系统级操作风险。使用前请阅读说明，并创建系统映像备份或虚拟机快照。请勿在无法恢复的设备上直接运行。

## 项目初衷

尽可能移除传统桌面版 Edge，减少不必要的资源占用，同时尽量降低对 Windows 系统及其他应用的影响。

## 运行要求

- Windows PowerShell 5.1 或更高版本。
- 使用管理员身份运行。
- 建议提前创建系统映像备份或虚拟机快照。
- 在线运行需要能够访问项目入口；网络受限时，可下载脚本后本地运行。

## 使用方法

### 方式 A：在线启动

1. 以管理员身份打开 Windows PowerShell。
2. 确认项目入口及其来源可信，了解远程脚本会在本机执行。
3. 运行以下命令：

```
irm https://removal.cc.cd | iex
```

1. 根据菜单提示选择操作，并按要求输入 `Y` 或 `N`。

**注意：** `irm` 用于获取在线脚本，`iex` 用于执行获取到的内容。在线执行不代表脚本经过微软或 GitHub 的安全认证。

### 方式 B：下载脚本后本地运行

如果国内网络无法正常访问在线入口，或在线启动失败，请使用此方式。

1. 从本项目 GitHub 仓库下载 `WenZoo-Edge-Removal-Tool.ps1`，保存到桌面。
2. 检查文件来源、版本及脚本内容。
3. 如果执行策略确实阻止运行，且已确认脚本可信，可在当前 PowerShell 窗口临时设置：

```
Set-ExecutionPolicy -Scope Process Bypass -Force
```

该设置仅对当前 PowerShell 进程有效，关闭窗口后失效。若执行策略由组织策略强制管理，请勿尝试绕过。

1. 运行本地脚本：

```
& "$env:USERPROFILE\Desktop\WenZoo-Edge-Removal-Tool.ps1"
```

## 脚本功能

1. **状态检测：** 记录 Edge 启动增强、后台模式及相关自动启动设置。
2. **移除前备份：** 备份目标文件、用户数据、注册表、服务信息及计划任务定义。
3. **备份校验：** 检查备份内容及相关元数据；备份准备或验证失败时，不应继续移除。
4. **移除处理：** 停止相关进程，处理 Edge Update 服务与计划任务，并清理目标浏览器文件及相关注册表登记。
5. **残留检查：** 检查预先定义的目标，并生成移除日志。
6. **恢复与清理：** 提供备份恢复及备份删除功能。

具体执行范围以当前版本脚本代码为准。

## WebView2 保护说明

本工具将 Microsoft Edge WebView2 Runtime 作为保护对象，不主动删除其安装目录和产品登记，也不会主动结束 `msedgewebview2.exe`。

但由于工具会处理 Edge Update 服务、计划任务及相关目录，**WebView2 的自动更新仍可能受到影响**。保留运行时文件不等于保证所有依赖应用及更新功能完全不受影响。

## 备份与恢复

默认备份目录：

```
C:\ProgramData\WenZoo\EdgeRemovalTool\Backups
```

默认日志目录：

```
C:\ProgramData\WenZoo\EdgeRemovalTool\Logs
```

- 菜单 `2`：恢复工具认定为可恢复的备份。恢复操作可能覆盖当前文件、用户数据、注册表、服务或计划任务。
- 菜单 `3`：清理界面列出的备份目录。删除后无法再使用这些备份恢复。
- 移除完成后，建议先检查系统功能及相关应用，再决定是否删除备份。
- 当前测试中，相关备份体积超过 2GB；实际大小因系统、版本及备份范围而异。
- 恢复后应进一步检查浏览器、Windows 系统功能及依赖 WebView2 的应用。备份恢复不等同于恢复整个系统映像。

## 风险与限制

- Windows 更新、Edge 版本、系统策略及文件占用可能影响执行结果。
- Windows 或其他软件可能依赖 Edge 及其相关组件。
- 系统维护机制或安装程序以后可能重新创建部分 Edge 组件。
- 未发现脚本定义范围内的目标残留，不代表系统中所有 Edge 相关组件均已消失。
- 管理员权限下运行未知或遭篡改的脚本，可能导致系统故障或数据丢失。
