# WenZoo Edge Removal Tool

**版本：v0.5.1**  

WenZoo Edge Removal Tool 是面向 Windows 的 PowerShell 工具，用于尽可能移除传统桌面版 Microsoft Edge，并提供移除前备份与恢复功能。本项目不是微软官方卸载程序，也不保证覆盖所有 Windows 版本、系统策略或未来更新带来的差异。

> [!CAUTION]
> 本工具会停止进程、禁用或删除 Edge Update 服务和计划任务、删除浏览器文件及注册表登记。**这是真正的系统修改操作，不是只读优化。** 使用前请阅读本文、确认你拥有这台电脑的管理权限，并创建可恢复的系统备份或虚拟机快照。不要在无法恢复的生产设备或组织管理设备上贸然运行。

## 使用方法

### 方式 A：在线启动

1. 以管理员身份打开 **Windows PowerShell**。
2. 确认域名是本项目在线入口，并理解远程脚本会在本机立即执行。
3. 运行：

   ```powershell
   irm https://removal.cc.cd | iex
   ```

4. 按菜单提示选择操作并输入 `Y` 或 `N`。

`irm` 是 `Invoke-RestMethod` 的别名，负责获取在线脚本；`iex` 是 `Invoke-Expression` 的别名，会在当前 PowerShell 会话执行获取到的内容。脚本是在本机执行，但内容来自网络；**在线执行不等于代码经过微软或 GitHub 的安全认证**。

### 方式 B：先下载、检查，再从本地运行

注：国内网络稳定不稳定,在线启动可能失败，可使用此方式。

1、下载WenZoo-Edge-Removal-Tool.ps1到桌面。

2、如果用户下载了本地 .ps1 文件，且当前执行策略确实阻止运行，在已核实文件来源并信任内容的前提下，可仅对当前 PowerShell 进程临时设置：

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
```

此设置仅作用于当前 PowerShell 进程，关闭窗口后即失效，不会永久改变其他会话的执行策略。但它会放宽当前窗口内的脚本执行限制，不得用于未知或未经审查的文件。若执行策略由组织组策略强制管理，不要尝试绕过组织规定。

3、确认来源、版本和代码后，再在管理员 PowerShell 中运行：

```powershell
& "$env:USERPROFILE\Desktop\WenZoo-Edge-Removal-Tool.ps1"
```

不要为了运行未知来源的脚本而盲目放宽执行策略。

## 脚本工作原理

工具在当前管理员 PowerShell 进程中运行，核心流程如下：

1. **记录启动状态：** 保存 Startup Boost（启动增强）、后台模式、相关用户自动启动项及策略检测结果。
2. **暂时关闭启动机制：** 禁用启动增强/后台模式和识别到的 Edge 自动启动项，自动关闭传统 Edge 进程，降低浏览器在清理期间重新启动的机会。
3. **创建强制备份：** 备份检测到的 Edge、EdgeCore、EdgeUpdate 目录、用户本地 Edge 数据目录、相关快捷方式、目标注册表项、服务注册表快照及 Edge Update 计划任务定义。
4. **验证备份：** 对文件和目录进行内容或 SHA-256 校验，同时检查注册表导出、计划任务 XML 和备份元数据。备份准备或验证失败时，不应继续移除。
5. **停止 Edge Update：** 删除目标更新计划任务，停止并禁用识别到的 Edge Update 服务，停止已核实路径属于 Edge Update 的进程，并检查相关目标是否已停止。
6. **运行官方卸载器并继续直接清理：** v0.5.1 将已观察到的官方 Edge 卸载器退出码 `93` 记录为信息日志，再继续直接清理。该返回码本身不作为卸载成功的证据，工具仍会独立核验实际清理结果。
7. **清理与残留核验：** 清理目标浏览器目录、快捷方式及特定 Edge 注册表登记，独立检查预先定义的残留目标，并生成移除报告。
8. **保留备份：** 清理完成后默认保留备份，并询问是否删除。用户在可继续异常提示中选择取消时，工具会尝试恢复原状态；只有回滚和验证成功后才删除本次临时备份。回滚失败时保留备份供再次恢复。

### WebView2 保护范围

工具明确排除 Microsoft Edge WebView2 Runtime 的安装目录和产品登记，也不会主动结束 `msedgewebview2.exe`。但是，工具会禁用或移除 Edge Update 服务、任务及相关目录，**可能影响 WebView2 Runtime 的自动更新**。保护 WebView2 文件和产品登记，不等于保证所有 WebView2 更新机制、应用集成或依赖功能绝对不受影响。

## 备份与恢复

移除前会对移除项做备份处理，中途失败可菜单2恢复移除项，移除结束会提示是否清理备份（相关备份2G以上，推荐在确保系统稳定后再清除备份。），菜单3可随时清理移除操作带来的备份文件（一旦使用无法恢复，请确保系统稳定后清理）。

默认备份目录：

```text
C:\ProgramData\WenZoo\EdgeRemovalTool\Backups
```

默认日志目录：

```text
C:\ProgramData\WenZoo\EdgeRemovalTool\Logs
```

- 移除前，确认日志显示备份完成，并且相关文件/目录的校验通过。
- 移除后建议先做兼容性检查，再决定是否删除备份。
- 菜单 `2` 会选择工具认定为可恢复的备份，并可能覆盖当前文件、用户 Edge 配置、注册表、服务或计划任务。
- 菜单 `3` 删除界面列出的备份目录。**删除不可撤销；删除后工具无法使用这些备份恢复。**
- 不要把备份直接用于其他电脑或其他 Windows 账户。请在原测试机和原 Windows 账户下恢复。
- 恢复成功的日志还应辅以实际检查，例如启动 Edge、打开网页、检查 Windows 搜索/文件资源管理器，以及检查需要 WebView2 的应用。备份恢复不等同于恢复整个 Windows 系统映像。

## 风险与限制

- **系统兼容性：** Windows 更新、Edge 版本、服务权限、文件占用或策略可能导致结果不同。Windows 组件或第三方软件可能依赖 Edge 或相关协议。
- **自动修复/重新安装：** Windows 更新、Edge 安装程序或系统维护机制以后可能重新创建部分组件。工具无法保证 Edge 永远不会被重新安装。
- **WebView2 更新：** 工具不主动删除 WebView2 Runtime 本身，但处理 Edge Update 可能影响其自动更新；使用 WebView2 的应用仍可能依赖该运行时。
- **浏览器数据：** 工具会处理用户本地 Edge 数据目录。若需要保留用户数据，必须确保备份成功，并在确认不再需要恢复前保留备份。
- **强制清理：** 已知退出码 `93` 会作为信息日志记录，之后由工具独立清理并核验残留。“未发现目标残留”仅表示脚本定义的检查范围内未发现目标，不代表 Windows 上所有 Edge 相关组件都不存在。
- **备份空间和时间：** Edge、EdgeCore 和用户配置目录可能较大；完整内容哈希校验会占用磁盘空间并花费时间。
- **在线执行的供应链风险：** 在线命令会执行当前域名返回的代码。若域名、DNS、托管账户、仓库或发布流程遭到篡改，返回内容也可能改变。高风险环境应先从仓库获取脚本并人工审查，再运行本地版本。
- **管理员权限风险：** 工具需要较高权限；错误或被篡改的脚本可能造成系统级影响。不要在重要工作未保存、运行关键任务或无法恢复的设备上执行。
